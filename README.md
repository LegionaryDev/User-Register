# User-Register
Objetivo do projeto é criar um crud com banco de dados de registro de usuários em java com o framework Spring boot.
Dependências utilizadas (Spring Data JPA para requisições com o banco de dados, o banco de dados relacional H2database e Spring Web). Contando também com a tecnologias (Java 25, Spring Boot 4 e maven).
A arquitetura principal utilizada é a Arquitetura em Camadas (Layered Architecture), estruturada especificamente para uma API REST.
